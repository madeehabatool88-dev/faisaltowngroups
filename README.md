# FaisalTown Groups Website

Astro project for `www.faisaltowngroups.com`.

## Project

- Homepage: `src/pages/index.astro`
- Global styles: `src/styles/global.css`
- Layout and SEO metadata: `src/layouts/BaseLayout.astro`
- Public media: `public/assets`
- Static robots and sitemap files: `public/robots.txt`, `public/sitemap.xml`

## Run Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

The project is configured as a static Astro site with canonical domain `https://www.faisaltowngroups.com`.
